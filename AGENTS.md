# KidIT Manager

## Production deployments

- The primary Vercel production project is `kid-it-manager-8k8k`, serving `https://kid-it-manager-8k8k.vercel.app`.
- When asked to deploy KidIT Manager to production, target that project explicitly and verify the new deployment on its production domain.
- Do not deploy to `kid-it-manager.vercel.app` or use a shared production branch push that would also deploy there, unless the user explicitly requests it.
